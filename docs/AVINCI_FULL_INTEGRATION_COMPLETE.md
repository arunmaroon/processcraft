## 🚀 How to Use

### **Access AI Agents**
1. Click **"AI Agents"** in the sidebar
2. You see the complete **AvinciDashboard**
3. Navigate between tabs:
   - **Dashboard** - Overview and stats
   - **Generate Agents** - Upload documents to create agents
   - **Agent Library** - Browse and manage agents
   - **Single Chat** - Chat with individual agents
   - **Group Chat** - Multi-agent conversations
   - **Design Feedback** - Get UI feedback from agents

### **Generate New Agents**
1. Go to **"Generate Agents"** tab
2. Upload research documents (PDF, Excel, CSV, etc.)
3. Set number of agents to generate (1-10)
4. Click **"Generate AI Agents"**
5. Agents appear in **"Agent Library"**

### **Manage Agents**
1. Go to **"Agent Library"** tab
2. View all agents in grid layout
3. Click **"View"** for detailed profile
4. Click **"Chat"** to start conversation
5. Use **menu (⋮)** for sleep/wake/delete actions
