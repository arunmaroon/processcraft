# 🚀 Grok AI Integration Setup

## Overview
ProcessCraft now uses **Grok AI** (by xAI) as the primary LLM for generating world-class Product Requirements Documents. Grok provides superior reasoning, creativity, and business acumen for creating exceptional PRDs.

## 🔑 Getting Your Grok API Key

### Step 1: Sign Up for xAI
1. Visit [https://console.x.ai/](https://console.x.ai/)
2. Sign up for an xAI account
3. Verify your email address

### Step 2: Get API Access
1. Go to the API section in your xAI console
2. Request API access (may require approval)
3. Once approved, generate your API key
4. Copy the API key for configuration

### Step 3: Configure Environment
1. Copy `env.example` to `.env` in the project root
2. Add your Grok API key:
   ```bash
   GROK_API_KEY=your_actual_grok_api_key_here
   ```

## 🔧 Troubleshooting

### Common Issues

**1. API Key Not Working**
- Verify the key is correct and active
- Check if API access is approved
- Ensure no extra spaces in the key

**2. Rate Limiting**
- Grok has rate limits based on your plan
- The system will fallback to OpenAI if needed
- Monitor usage in xAI console

**3. Generation Quality**
- Grok provides the highest quality output
- If issues persist, check the fallback system
- Review the generated content for improvements
