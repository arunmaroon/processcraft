## 🚀 **How to Use:**

### **Access Complete Avinci System:**
1. **Click "AI Chat"** in the sidebar
2. **Navigate between tabs:**
   - **Single Chat** - Chat with individual agents
   - **Group Chat** - Multi-agent conversations
   - **Agent Library** - Manage all agents
   - **Settings** - Configure chat system

### **Single Chat:**
1. Go to **"Single Chat"** tab
2. Select an agent from the sidebar
3. Start typing messages
4. Real-time conversation with AI agent

### **Group Chat:**
1. Go to **"Group Chat"** tab
2. Select multiple agents
3. Send messages to the group
4. All agents participate in conversation

### **Agent Library:**
1. Go to **"Agent Library"** tab
2. Browse, search, and filter agents
3. Click **"Chat"** to start individual conversation
4. Click **"View"** for detailed agent profile
5. Manage agent status (sleep/wake/delete)
